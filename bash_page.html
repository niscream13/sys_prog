Операційна система GNU/Linux

GNU/Linux — це сімейство вільних операційних систем, у якому ядро Linux поєднується з інструментами проєкту GNU та іншими програмами.

Linux використовують на серверах, у хмарних платформах, вбудованих пристроях і на персональних комп’ютерах. Система відома гнучкістю, стабільністю та можливістю налаштовувати робоче середовище під власні потреби.

Bash — одна з найпоширеніших командних оболонок Linux. Вона дає змогу виконувати команди, поєднувати їх у сценарії та автоматизувати повторювані дії.

Популярні дистрибутиви

Дистрибутив — це готова версія Linux з ядром, програмами, менеджером пакунків і власними налаштуваннями.

Ubuntu

Поширений дистрибутив для початківців і щоденної роботи.

Debian

Стабільна система, на основі якої створено багато інших дистрибутивів.

Fedora

Сучасний дистрибутив із новими версіями програм.

Arch Linux

Гнучка система для детального налаштування.

Linux Mint

Зручний варіант для щоденної роботи.

openSUSE

Дистрибутив із потужними інструментами адміністрування.

10 базових команд Linux CLI

Команди виконують у терміналі. Значення в кутових дужках потрібно замінити власними даними.

pwd

Показує поточну робочу папку.

echo "текст"

Виводить текст у термінал.

ls

Показує файли та папки.

cd <папка>

Переходить до папки.

touch <файл>

Створює порожній файл.

mkdir <папка>

Створює нову папку.

cp <звідки> <куди>

Копіює файл або папку.

mv <звідки> <куди>

Переміщує або перейменовує файл.

rm <файл>

Видаляє файл.

history

Показує історію команд.

Bash-скрипт

Імітація авторизації

Сценарій запитує ім’я користувача й пароль, а потім перевіряє введені значення. Це навчальний приклад, а не безпечний спосіб зберігати паролі.

login.sh 
#!/usr/bin/env bash

read -p "Логін: " login
read -s -p "Пароль: " password
echo

if [[ "$login" == "student" && "$password" == "linux" ]]; then
  echo "Вітаємо, $login! Авторизацію виконано."
else
  echo "Помилка: неправильний логін або пароль."
fi
